# 用户 ABI（本阶段）

C 与 Rust 使用 RISC-V LP64D ABI。系统调用号放 a7，参数放 a0～a5，返回值放 a0；负值表示错误。此章只保存整数上下文，用户不得使用浮点或向量指令。

| 编号 | 调用 | 结果 |
|---|---|---|
| 0 | hello，无参数 | 内核打印 `proczero: hello world!\n`，返回 0 |

未知调用返回 -38。用户入口 0x1000，代码、数据和 BSS 的总内存占用不超过一页；先清零整页再复制平坦镜像。代码数据页 RWXU，用户栈 RWU，用户栈顶 `(1<<38)-8192` 且 16 字节对齐。初始 heap_top=0x2000、ustack_npage=1，最低页不映射。trampoline/trapframe 不设 U，对用户不可访问。

用户调用链：程序 → 用户库 → 架构 ABI 适配 → ecall。内核调用链：用户 trap → 架构解码 → trap 内最小 hello/未知号分支 → 架构返回值接口 → 返回准备。返回值接口只在 ecall 路径调用，写 a0 并将 frame.epc 增加 4；返回准备将该值写入 sepc，不能再加 4。中断不推进 PC。

共享 uapi 只定义调用契约，不含 ecall。本章没有独立的通用 syscall 分派或服务模块。SBI 是 S-mode 到固件的另一套接口。跨语言组合须由学生接入符合相同入口、镜像、堆栈和调用契约的平坦镜像，不依赖内核的实现语言。
